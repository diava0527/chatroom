# 大厅聊天流程

## 流程目标

让已进入大厅的用户发送大厅消息，并实时广播给在线相关用户。

## 参与对象

- 浏览器前端
- WebSocket 控制器
- 消息分发模块
- 大厅聊天模块
- 大厅消息内存存储
- 连接管理模块

## 前置条件

- 用户已经登录
- 用户 WebSocket 已连接
- 用户已经进入大厅

## 主流程

1. 前端发送 `lobby.message.send`
2. WebSocket 控制器接收原始消息
3. 消息分发模块识别为大厅发送事件
4. 大厅聊天模块生成大厅消息对象
5. 大厅消息写入大厅消息内存存储
6. 连接管理模块将消息广播给在线相关用户

## 异常流程

1. 如果用户未登录或 `sessionId` 已失效，则拒绝处理
2. 如果用户未进入大厅，则拒绝发送大厅消息
3. 如果消息内容为空，则返回消息格式错误

## 输出结果

- 成功：大厅消息被保存并广播
- 失败：返回对应错误信息

## 关键规则

- 大厅消息属于公共消息
- 大厅消息会进入大厅消息历史池
