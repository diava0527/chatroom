# 当前私聊窗口历史流程

## 流程目标

返回指定当前私聊窗口创建之后积累的消息记录。

## 参与对象

- 浏览器前端
- WebSocket 控制器
- 消息分发模块
- 私聊模块
- 私聊窗口内存存储

## 前置条件

- 用户已经登录
- 用户 WebSocket 已连接
- 当前私聊窗口已存在

## 主流程

1. 前端发送 `private.history.pull`
2. 请求中携带 `privateSessionId`
3. WebSocket 控制器接收原始消息
4. 消息分发模块识别为私聊历史拉取事件
5. 私聊模块按 `privateSessionId` 查找对应窗口
6. 私聊模块读取该窗口内的消息列表
7. 系统返回当前窗口的历史消息

## 异常流程

1. 如果 `privateSessionId` 不存在，则返回会话不存在
2. 如果当前用户不是该窗口参与者，则拒绝访问
3. 如果当前窗口还没有消息，则返回空列表

## 输出结果

- 返回该当前私聊窗口的消息列表

## 关键规则

- 只记录当前窗口创建之后的消息
- 重新创建新窗口后，历史边界重新开始计算
