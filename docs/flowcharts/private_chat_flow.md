# 私聊消息收发流程

## 流程目标

在指定私聊窗口会话中发送消息，并实时推送给双方。

## 参与对象

- 浏览器前端
- WebSocket 控制器
- 消息分发模块
- 私聊模块
- 私聊窗口内存存储
- 连接管理模块

## 前置条件

- 用户已经登录
- 用户 WebSocket 已连接
- 当前私聊窗口已创建

## 主流程

1. 前端发送 `private.message.send`
2. 请求中携带 `privateSessionId` 和消息内容
3. WebSocket 控制器接收原始消息
4. 消息分发模块识别为私聊发送事件
5. 私聊模块校验该窗口是否存在
6. 私聊模块生成私聊消息对象
7. 私聊消息写入对应私聊窗口会话
8. 连接管理模块把消息推送给发送方和接收方

## 异常流程

1. 如果 `privateSessionId` 不存在，则返回会话错误
2. 如果发送者不属于该窗口参与者，则拒绝发送
3. 如果接收方离线，则系统只保留当前窗口消息记录

## 输出结果

- 成功：消息保存成功并实时推送
- 失败：返回错误原因

## 关键规则

- 私聊消息只写入当前私聊窗口
- 不与其他私聊窗口共享历史
