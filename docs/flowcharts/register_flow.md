# 注册流程

## 流程目标

完成新用户注册，并保证昵称全局唯一。

## 参与对象

- 浏览器前端
- HTTP 注册接口
- 用户模块
- 用户内存存储

## 前置条件

- 用户尚未注册
- 前端准备好 `nickname` 和 `password`

## 主流程

1. 前端向 `/api/v1/auth/register` 发送注册请求
2. 注册接口解析 `nickname` 和 `password`
3. 用户模块检查昵称是否已存在
4. 如果昵称不存在，则构造用户信息并写入用户内存存储
5. 注册接口返回注册成功响应

## 异常流程

1. 如果昵称已存在，则直接返回注册失败
2. 如果请求参数不完整，则返回参数错误

## 输出结果

- 成功：返回注册成功信息
- 失败：返回失败原因，例如昵称重复

## 关键规则

- 昵称唯一，不可重复
- 当前阶段只写入内存，不写数据库
