# WebSocket 建连与在线状态流程

## 流程目标

通过 `sessionId` 建立 WebSocket 连接，并把用户记为在线。

## 参与对象

- 浏览器前端
- WebSocket 路由
- WebSocket 控制器
- 鉴权模块
- 连接管理模块
- 在线用户模块

## 前置条件

- 用户已经通过 HTTP 登录
- 前端已拿到有效 `sessionId`

## 主流程

1. 前端使用 `/ws/chat?sessionId=xxx` 发起 WebSocket 连接
2. WebSocket 控制器提取 `sessionId`
3. 鉴权模块校验 `sessionId` 是否有效
4. 如果有效，则解析出对应昵称
5. 连接管理模块建立“昵称 <-> WebSocket连接”的关联
6. 在线用户模块将该用户记为在线
7. 系统可以向所有在线用户广播最新在线列表

## 断开流程

1. 如果浏览器断开 WebSocket
2. 连接管理模块解除连接绑定
3. 在线用户模块将该用户记为离线
4. 系统向其他在线用户广播在线列表变化

## 异常流程

1. 如果 `sessionId` 无效，则拒绝连接
2. 如果连接初始化失败，则不进入在线用户列表

## 关键规则

- 只有“已登录且 WebSocket 已连接”的用户才算在线
- 在线状态不只看登录，还必须看 WebSocket 连接是否存在
