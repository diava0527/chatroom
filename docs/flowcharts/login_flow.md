# 登录流程

## 流程目标

校验昵称和密码，并在成功后生成 `sessionId`。

## 参与对象

- 浏览器前端
- HTTP 登录接口
- 鉴权模块
- 用户内存存储
- 会话内存存储

## 前置条件

- 用户已经注册
- 前端准备好 `nickname` 和 `password`

## 主流程

1. 前端向 `/api/v1/auth/login` 发送登录请求
2. 登录接口解析昵称和密码
3. 鉴权模块根据昵称查询用户信息
4. 鉴权模块校验密码是否正确
5. 如果校验成功，则生成 `sessionId`
6. 系统把 `sessionId` 和昵称的映射写入会话内存存储
7. 登录接口向前端返回 `sessionId`

## 异常流程

1. 如果昵称不存在，则返回登录失败
2. 如果密码错误，则返回登录失败
3. 如果请求参数不完整，则返回参数错误

## 输出结果

- 成功：返回 `nickname` 和 `sessionId`
- 失败：返回登录失败原因

## 关键规则

- 登录凭证是昵称和密码
- 登录成功后只返回 `sessionId`，不再返回账号
