# 登出与清理流程

## 流程目标

使当前 `sessionId` 失效，并清空和该用户有关的私聊窗口。

## 参与对象

- 浏览器前端
- HTTP 登出接口
- 鉴权模块
- 会话内存存储
- 在线用户模块
- 私聊模块

## 前置条件

- 用户已经登录
- 前端持有有效 `sessionId`

## 主流程

1. 前端向 `/api/v1/auth/logout` 发送登出请求
2. 登出接口从请求头中读取 `sessionId`
3. 鉴权模块根据 `sessionId` 找到对应用户昵称
4. 会话内存存储删除该 `sessionId`
5. 在线用户模块将该用户标记为离线
6. 私聊模块清空和该用户有关的全部当前私聊窗口
7. 登出接口返回成功响应

## 异常流程

1. 如果 `sessionId` 无效，则返回鉴权失败
2. 如果用户本来就不在线，则仍可执行会话失效清理

## 输出结果

- 成功：当前登录态失效，私聊窗口被清理
- 失败：返回无效会话等错误信息

## 关键规则

- 登出后清空和该用户有关的私聊窗口
- 登出后原 `sessionId` 不可继续使用
