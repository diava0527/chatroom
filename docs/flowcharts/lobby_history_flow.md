# 大厅历史可见记录流程

## 流程目标

只向用户返回其进入大厅之后产生的大厅消息。

## 参与对象

- 浏览器前端
- WebSocket 控制器
- 消息分发模块
- 大厅聊天模块
- 大厅会话存储
- 大厅消息存储

## 前置条件

- 用户已经登录
- 用户 WebSocket 已连接
- 用户已经进入大厅

## 主流程

1. 前端发送 `lobby.history.pull`
2. WebSocket 控制器接收请求
3. 消息分发模块识别为大厅历史拉取事件
4. 大厅模块读取该用户的进入大厅时间
5. 大厅模块按进入时间筛选大厅消息
6. 系统只返回进入大厅之后的消息列表

## 异常流程

1. 如果用户还未进入大厅，则没有历史边界，返回空结果或错误提示
2. 如果没有新消息，则返回空列表

## 输出结果

- 返回当前用户可见的大厅历史消息列表

## 关键规则

- 进入大厅之前的消息不显示
- 可见历史边界按单个用户进入大厅的时刻独立计算
