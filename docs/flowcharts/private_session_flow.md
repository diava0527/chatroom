# 创建私聊窗口会话流程

## 流程目标

由用户主动创建一个新的当前私聊窗口会话。

## 参与对象

- 浏览器前端
- HTTP 创建私聊窗口接口
- 鉴权模块
- 在线用户模块
- 私聊模块
- 私聊窗口内存存储

## 前置条件

- 用户已经登录
- 前端持有有效 `sessionId`
- 目标用户当前在线

## 主流程

1. 前端向 `/api/v1/private-chat/session` 发送创建私聊窗口请求
2. 接口读取请求头中的 `sessionId`
3. 鉴权模块校验 `sessionId`
4. 接口解析 `targetNickname`
5. 在线用户模块检查目标用户是否在线
6. 私聊模块创建新的当前私聊窗口会话
7. 私聊窗口写入私聊内存存储
8. 接口返回 `privateSessionId`

## 异常流程

1. 如果 `sessionId` 无效，则返回鉴权失败
2. 如果目标用户不在线，则返回创建失败
3. 如果目标昵称不存在，则返回用户不存在

## 输出结果

- 成功：返回新的 `privateSessionId`
- 失败：返回错误原因

## 关键规则

- 私聊窗口由前端主动创建
- 每次新建窗口都视为一个新的当前私聊会话
